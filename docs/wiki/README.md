# Block Language Wiki

This directory is the version-controlled Markdown source for the Block
documentation. The repository also publishes a visual documentation site from
the root-level `wiki*.html` pages. Keeping this Markdown copy in the repository
makes the guides reviewable, searchable, and available even when GitHub's
separate Wiki feature is not enabled.

## Pages

- [Installation](Installation.md) — editions, installer setup, and verification.
- [Syntax](Syntax.md) — native Block syntax and runtime tags.
- [Polyglot state](Polyglot-State.md) — how values cross runtime boundaries.
- [Architecture](Architecture.md) — parser, executor, process lifecycle, and isolation.
- [Troubleshooting](Troubleshooting.md) — common installation and execution failures.

For the visual version, open the [Block documentation site](../../wiki.html)
or its focused pages: [installation](../../wiki-install.html),
[syntax](../../wiki-syntax.html), [polyglot blocks](../../wiki-polyglot.html),
and [architecture](../../wiki-architecture.html).
